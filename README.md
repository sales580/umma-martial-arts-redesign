# UMMA Martial Arts: website redesign preview

A design preview of a redesigned website for UMMA Martial Arts (United Muslim Martial Arts).

This is **not the official UMMA website**. The official site is https://ummamartialarts.ca/. Details on this preview may change before launch, and search engines are asked not to index it.

Plain static files (HTML, CSS, JavaScript, photos). No build step is needed to view it.
